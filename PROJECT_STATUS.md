# Sysmon: статус работ

Обновлено: 13 августа 2026 года.

## Готово

- `views.py` разделён на модули по областям ответственности;
- добавлены Docker Compose, PostgreSQL, Redis и интерактивная первичная настройка;
- подготовлен обезличенный тестовый набор и читаемая схема связей на карте;
- реализована базовая микросегментация и аудит политик;
- добавлены проверки основных пользовательских сценариев и внешних интеграций;
- удалены дубли статики, устаревшие модули и локальные данные;
- описана синхронизация файлов Nagios через cron и отдельный SSH-ключ.

## Следующие приоритеты

1. Перенести пароль PostgreSQL и остальные эксплуатационные секреты в Docker
   secrets или секрет-хранилище целевой платформы.
2. Проверить синхронизацию с реальным Nagios и права пользователя только на
   чтение `status.dat` и `nagios.log`.
3. Добавить reverse proxy, TLS и резервное копирование PostgreSQL для
   промышленного развёртывания.
4. Привести оставшиеся страницы к единой дизайн-системе.
5. Добавить скриншоты, архитектурную схему и описание восстановления из backup.

## Ближайший результат

Проверить развёртывание на чистом сервере по README: интерактивное создание
администратора, выбор тестового набора, запуск контейнеров и получение файлов Nagios.
